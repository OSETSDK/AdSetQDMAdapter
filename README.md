# AdSetQDMAdapter

佳投 M 渠道适配器，后端平台标识为 `tuiyi`，首发候选版本 `2.0.0.0`。

## 当前状态

本目录是独立交付候选。它保留 `OSETCoreAd >= 7.0.4.0` 和
`AdSetQDMAdSDK = 1.4.16` 的依赖约束。最低 Core 版本需要包含 `tuiyi`
运行时映射；该 Core 依赖尚未完成远端发布和消费者联验，因此当前不能将此候选
视为可安装、可投放的正式版本。原研发目录未改动。

## 支持范围

| 广告格式 | 状态 |
| --- | --- |
| 开屏 Splash | 已有适配实现，使用宿主指定窗口 |
| 插屏 Interstitial | 已有适配实现；半屏与全屏由广告位决定 |
| 激励视频 Rewarded | 已有适配实现；真实奖励校验与完播分别处理 |
| Native 模板 | 已有适配实现；使用渠道返回的原视图 |
| NativeData 自渲染交互 | 未开放，Core 映射保持空值 |
| Banner / 独立 FullscreenVideo / Draw | 不支持 |

自渲染素材桥接源码随候选保留，但尚无已确认的可逆解绑契约，不注册厂商曝光、点击，
不能作为可用的自渲染交互入口。

## 集成条件

适配器产物为静态 XCFramework，不内置 Core 或渠道 SDK。M 渠道 SDK 是动态
Framework，最终宿主需要正确嵌入和签名。Podspec 保留 `-ObjC`，让 Core 可以
按类名发现适配器。

本轮构建仅证明候选源码能使用本地最新 Core SPI 头与真实 M SDK 头编译，并完成
静态切片及符号检查；消费者链接、运行时发现、初始化和真实广告验收仍需在 Core
依赖就绪后单独完成。
